# Building a Desired Habit

As an early default, build reliable initiation before increasing duration, intensity, or identity emphasis. A desired habit should become easier to enter and sufficiently rewarding to repeat; it should not depend on a daily argument with willpower. When a course, job, rehabilitation plan, or other external requirement has a minimum effective dose, pair the starter with a realistic route to that requirement rather than treating the tiny action as sufficient.

## Define the Real Outcome

Translate “I want to do this every day” into:

- the benefit the user actually wants;
- a context in which the behavior is useful;
- the smallest observable start;
- a flexible successful version;
- evidence that the habit is helping rather than merely producing a streak.

Do not assume daily frequency is necessary. Keep it only when it serves the outcome and fits the user's life. Missing one opportunity is not a reset; return at the next available cue.

## Build the Start Chain

Design: existing anchor -> visible material -> starter action -> satisfying core action -> clear close.

1. **Anchor**: Choose a stable event already present, such as finishing lunch, arriving at the library, or placing the phone on charge. Avoid vague cues like “when I have time.”
2. **Visible material**: Put the book, file, clothing, or tool where the action occurs. Prepare the exact next page or task.
3. **Starter action**: Make the entry physical and small: open at the bookmark, read one paragraph, put on shoes, or write one rough sentence.
4. **Core action**: At first, allow flexible continuation when the outcome permits it. For external deadlines or minimum effective doses, define a bounded core unit and add appropriate structure after entry becomes reliable.
5. **Close**: Mark the next entry point and stop without guilt. A good close makes tomorrow's start easier.

Treat any self-chosen duration, page count, or frequency as a temporary experiment threshold unless supported by an external requirement.

## Diagnose Failure to Maintain

- **The cue never fires**: attach the behavior to a more stable event.
- **The material is not ready**: prepare the next entry point before closing.
- **The start still feels aversive**: shrink it or choose an easier version.
- **The activity is unrewarding**: change content, difficulty, format, location, or add immediate satisfaction.
- **A competing reward is closer**: separate or add friction to the competing behavior at the chosen cue.
- **The time has low energy**: move the cue; do not interpret exhaustion as lack of values.
- **The quota causes avoidance**: evaluate starts and useful engagement before volume.

If the user has already reported that a friction step such as moving the phone away is not executable, do not reuse it as a prerequisite. Start with a smaller off-ramp: pause the current content, turn the screen face down while keeping a hand on it, place the open book beside or partly over the phone, or read the starter while the phone remains within reach. Increase separation only after the starter can occur reliably.

## Reading Protocol

For regular reading, first identify the purpose: enjoyment, learning, sleep transition, or professional growth. These may require different books, formats, and times.

Use one main experiment:

- place one chosen book at the reading location, already opened or bookmarked;
- connect reading to one stable anchor;
- define the starter as opening the book and reading one paragraph or another deliberately tiny unit;
- permit stopping after the starter during the first phase;
- after reading, place the bookmark at the exact next entry and keep the book visible;
- if the book repeatedly fails to hold attention, test a different book or format before blaming discipline.

If reading is intended to replace late-night phone use, build a small transition from phone input to the open book. Make the book physically visible at the same location and use the smallest phone off-ramp the user can actually perform. Do not require full phone separation or an ambitious page quota when those requirements block the reading start.

## Review

Review a short experiment using:

- how often the starter occurred when the cue appeared;
- how much resistance appeared before starting;
- whether engagement sometimes continued naturally;
- whether the habit improved the intended outcome;
- whether the competing behavior weakened;
- how quickly the user returned after a missed opportunity.

If starts remain rare, change the cue, material placement, starter size, or reward. Do not respond by adding several more rules.

If starts are reliable but useful engagement does not grow, stop shrinking the starter. Diagnose content, difficulty, feedback, interruptions, energy, and session design.
